# Design Haven

Design Haven is an inspiration-first interior design web experience designed for people with a creative mindset, including homeowners, people renovating older homes, and people with homes under construction. The platform is intended to help visitors explore interior design possibilities, shape their ideas, and naturally progress toward a project enquiry.

## Project Goals

1. Provide interior design inspiration and ideas.
2. Help visitors explore and refine their vision.
3. Create a clear and engaging journey toward project enquiry.
4. Demonstrate a structured prompt-engineering workflow.

## User Journey

Curiosity  
→ Inspiration  
→ Exploration  
→ Possibility  
→ Confidence  
→ Action

## Prompt Engineering Approach

Business Context  
→ Prompt Design  
→ AI Content Generation  
→ Content Evaluation  
→ Content Refinement  
→ Website Implementation

All AI-generated content is reviewed and refined before implementation. Unsupported business claims and fabricated information are not accepted as final content.

## UI/UX Direction

Final creative decisions are controlled by the project owner. The current UI/UX reference ecosystem includes:

- React Bits
- UI/UX Pro Max Skill
- Amicro Micro-transitions
- KokonutUI

These reference resources are maintained as options for design inspiration; every resource will not necessarily be used in the final implementation.
